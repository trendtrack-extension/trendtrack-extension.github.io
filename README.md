# Extension Notes

The TrendTrack extension is the free Chrome add-on attached to an ecommerce research suite. Here is what the official page confirms, and what it leaves unsaid.

**Read the full page:** https://trendtrack-extension.github.io/

Install it if you already spend your day on other people's Shopify stores and you want store information without leaving the tab you are on. Do not install it expecting the full platform for free, because it sits in the free tools section as a companion to a paid suite, and browser add-ons in this category are usually a thin window onto the dashboard. The honest caveat is that the official page does not enumerate what the add-on shows, so treat any detailed feature list you read elsewhere, including on review sites, as unverified. Reachara is what we reach for when the question is which ads a competitor is running rather than what a single store looks like.
